# PBL 06 — Listas em Python

Repositório com exercícios práticos sobre **listas** em Python, desenvolvidos como parte de estudos de programação.

---

## Estrutura do Repositório

| Arquivo | Descrição |
|---|---|
| `exer1.py` | Criação de lista com números aleatórios e exibição na tela |
| `exer2.py` | Leitura de 3 números do usuário, armazenamento em lista e exibição |
| `exer3.py` | Leitura de uma frase e conversão em lista de palavras |
| `exer4.py` | Criação de lista com números de 1 a 10 e impressão em ordem reversa |
| `exer5.py` | Criação de lista de palavras e exibição da mais longa e da mais curta |
| `exer6.py` | Criação de listas com pares e ímpares de 1 a 10, junção em uma terceira lista |
| `exer7.py` | Criação de lista de 1 a 100 e exibição apenas dos números pares |
| `exer8.py` | Criação de lista com quadrados de 1 a 10 e cálculo da soma dos elementos |
| `exer9.py` | Lista com letras do alfabeto embaralhadas e jogo de adivinhação de posição |

---

## Conceitos Usados

- Criação e manipulação de listas
- Geração de números aleatórios com `random`
- Iteração com laços `for`
- Métodos de lista: `append`, `reverse`, `shuffle` 
- Entrada de dados com `input()`


---

## Como Executar

Certifique-se de ter o **Python 3** instalado. Então, digite no terminal:

**Linux / macOS (Bash):**
```bash
python3 exer1.py
```

**Windows (CMD):**
```cmd
python exer1.py
```
ou
```cmd
py exer1.py
```

Substitua `exer1.py` pelo arquivo desejado.
